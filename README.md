# Horoscope Mini-App

Добро пожаловать в мини-приложение гороскопа! Это простое и интуитивно понятное Telegram-приложение, которое позволяет пользователям быстро получать свой ежедневный, еженедельный или ежемесячный гороскоп для любого знака зодиака.

## Описание

Horoscope App - это Telegram-miniapp, разработанное с использованием Vue.js, которое предоставляет пользователям гороскопы на основе выбранного ими знака зодиака и периода. Приложение имеет чистый и адаптивный пользовательский интерфейс, поддерживает несколько языков (русский и английский) и переключение тем (светлая/темная).

## Возможности

*   **Выбор знака зодиака:** Легко выбирайте свой знак зодиака из списка.
*   **Выбор периода:** Получайте гороскопы на сегодня, неделю или месяц.
*   **Многоязычность:** Поддержка русского и английского языков.
*   **Переключение тем:** Переключайтесь между светлой и темной темами для комфортного просмотра.
*   **Интуитивно понятный интерфейс:** Простой и понятный пользовательский интерфейс для удобной навигации.

## Технологии

*   **Vue.js 3 + VueUse:** Прогрессивный фреймворк для создания пользовательских интерфейсов.
*   **Vue Router:** Для управления навигацией по приложению.
*   **Vue I18n:** Для интернационализации и локализации.
*   **Tailwind CSS:** Для быстрой и адаптивной стилизации.
*   **Vite:** Быстрый сборщик фронтенда, обеспечивающий мгновенный горячий модуль.

## Установка и запуск

Чтобы настроить и запустить проект локально, выполните следующие шаги:

### Требования

*   Node.js (рекомендуется LTS-версия)
*   npm или Yarn

### Шаги

1.  **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com/your-username/horoscope-miniapp.git
    cd horoscope-miniapp
    ```

    (Замените `https://github.com/your-username/horoscope-miniapp.git` на фактический URL вашего репозитория.)

2.  **Установите зависимости:**

    ```bash
    npm install
    # или
    yarn install
    ```

3.  **Запустите сервер разработки:**

    ```bash
    npm run dev
    # или
    yarn dev
    ```

    Приложение будет доступно по адресу `http://localhost:5173` (или другому порту, указанному в консоли).

4.  **Сборка для продакшена:**

    ```bash
    npm run build
    # или
    yarn build
    ```

    Это сгенерирует готовые к развертыванию файлы в каталоге `dist/`.

## Использование

1.  Откройте приложение в браузере.
2.  На главной странице выберите нужный знак зодиака.
3.  После выбора знака зодиака выберите период (например, "Сегодня", "На этой неделе", "В этом месяце").
4.  Приложение отобразит ваш гороскоп.
5.  Вы можете переключить язык, нажав на значок глобуса.
6.  Вы можете переключить тему (светлая/темная), нажав на значок луны/солнца.

## API

Приложение получает данные гороскопа из следующей конечной точки API:
`https://poker247tech.ru/get_horoscope/`

Это API ожидает POST-запрос со следующими параметрами в теле JSON:
*   `sign`: Slug знака зодиака (например, `aries`).
*   `language`: `original` для русского или `translated` для английского.
*   `period`: Период гороскопа (например, `today`, `week`, `month`).
